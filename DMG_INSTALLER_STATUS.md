# BlackJack .dmg Installer

## Проверка установщика

Ваш .dmg установщик работает корректно! ✅

### Что проверено:

1. **Структура файла**: .dmg файл корректно создан и имеет правильный формат
2. **Содержимое**: Приложение BlackJack.app присутствует в образе диска
3. **Метаданные**: Info.plist содержит корректную информацию о приложении
4. **Запуск**: Приложение успешно запускается после установки
5. **Размер**: ~23MB - оптимальный размер для распространения

### Файлы для распространения:

- `dist/BlackJack-1.0.0.dmg` - основной файл для распространения

### Инструкции для пользователей:

#### Системные требования:
- macOS 10.11 или новее
- Java не требуется (включен в приложение)

#### Установка:
1. Скачайте файл `BlackJack-1.0.0.dmg`
2. Дважды кликните по файлу для монтирования
3. Перетащите `BlackJack.app` в папку `Applications`
4. Запустите игру из папки Applications или Launchpad

#### Удаление:
1. Перейдите в папку Applications
2. Перетащите BlackJack.app в Корзину
3. Очистите Корзину

### Технические детали:

- **Bundle ID**: com.example.blackjack
- **Версия**: 1.0.0
- **Архитектура**: Universal (поддерживает Intel и Apple Silicon)
- **Java Runtime**: Включен в приложение (не требует установки Java)
- **Цифровая подпись**: Создана автоматически jpackage

### Для разработчиков:

#### Тестирование установщика:
```bash
./scripts/test-installer.sh
```

#### Улучшенная сборка:
```bash
./scripts/build-macos-improved.sh
```

### Проблемы и решения:

#### Если приложение не запускается:
1. Убедитесь, что разрешили запуск приложений от неподтвержденных разработчиков:
   - Системные настройки → Защита и безопасность
   - Разрешить приложения, загруженные из: App Store и от подтвержденных разработчиков

2. Если появляется предупреждение о безопасности:
   - Правый клик на BlackJack.app → Открыть
   - Подтвердите запуск в диалоговом окне

#### Для коммерческого распространения:
Рекомендуется получить Apple Developer ID для цифровой подписи:
1. Зарегистрируйтесь в Apple Developer Program
2. Получите Developer ID Application certificate
3. Подпишите приложение с помощью codesign
4. Нотариально заверьте приложение через Apple
